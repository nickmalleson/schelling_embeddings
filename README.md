# Schelling Embeddings

A model that uses text embeddings to define agents in a simple Schelling model.

## Version history

### v2 (current)
This repository contains the active development version (v2). This updates the model to include neighbourhoods.

### v1 (archived)
The first version of the project was published as: [Foundation Models and Embeddings for Nuanced Perception and Decision-Making in Agents](http://www.nickmalleson.co.uk///p/2025-08-SSC-Schelling_Embeddings.html). Presentation to the [Social Simulation Conference (SSC) 2025](https://ssc2025.tbm.tudelft.nl/), 25-29 August, Delft.

It has been preserved as a Git tag.
